# 光影构图小程序自测清单

用微信开发者工具打开 `photo/` 目录。占位 AppID 可先用 Mock（`config.js` 中 `cloudEnvId` 保持 `YOUR_CLOUD_ENV_ID`）。接入云开发后替换 AppID 与环境 ID，并上传全部云函数、按 `database/indexes.json` 建集合与索引。

## Phase 1 骨架 / 契约

### 常规
- 工程能编译启动，首页可打开，导航栏为暗色「光影构图」。
- `app.wxss` 全局色在首页、相机、预览、详情、个人中心一致，无页面私自换主色。
- 冷启动会走 `login`（Mock 下不报错）；云环境未配置时页面仍可用。
- 从首页进入相机 / 我的 / 详情，路径走 `contracts/navigation.js`，缺 `photoId` 或预览图会 Toast。

### 弱网 / 并发
- 开发者工具切「弱网 / 断网」：login 失败出现「登录未完成」Toast，不白屏。
- 连续快速点击「开始拍照」：按钮进入「打开中」，不会叠多个相机页。

## Phase 2 灵感广场

### 常规
- 默认热度排序，热度高的卡片靠前（如「海岸剪影」）。
- 切换「最新」后列表刷新，最新时间靠前。
- 上拉可分页（Mock 共 10 条，页大小 10，第二页为空并显示到底）。
- 点击卡片进入详情；空态「去拍摄」跳转相机。

### 弱网 / 并发
- 断网下拉：展示缓存并提示「已显示缓存内容」。
- 快速来回切换热度/最新：请求防抖，不出现错乱穿插。

## Phase 3 相机与相似场景

### 常规
- 授权相机后取景框有九宫格线。
- 拒绝相机权限：空态 +「去设置」。
- 点选风景/人像/建筑等，右侧出现最多 3 张相似场景卡片。
- 点击推荐卡片可进详情，不中断（返回后相机仍在）。
- 拍摄后进入预览，带上 sceneKey / 标签。

### 弱网 / 并发
- 拒绝定位：Toast 通用场景推荐，仍能出卡片。
- 推荐接口失败：卡片隐藏，拍摄仍可用。
- 连点快门：仅一次拍照，显示「处理中」。

## Phase 4 预览压缩与发布

### 常规
- 预览显示刚拍的图；可改标题、多选标签、自定义标签。
- 点发布出现 Loading「压缩并审核中」。
- 成功后 `reLaunch` 回首页并 Toast「已发布到社区」，广场能刷到新帖。
- 缺少预览图（清掉 payload 直开页面）显示空态。

### 弱网 / 并发
- 3 秒内连续发布：第二次提示过于频繁。
- 上传/发布失败：按钮恢复，不丢预览图，可重试。
- 发布中再次点击无效。

## Phase 5 点赞与内容安全

### 常规
- 广场/详情/我的均可点赞，红心与数字立即变化。
- 再点取消，数量回退。
- 标题或标签含「暴力」「色情」等：前端拦截，不发请求。
- Mock 审核失败码为 `SECURITY_FAIL`；云端走 `msgSecCheck` / `imgSecCheck`，失败不上架并写 `audit_logs`。

### 弱网 / 并发
- 点赞过程中断网：数量回滚并 Toast「点赞同步失败」。
- 同一照片连点：Loading/锁生效，最终与服务端一致。
- 两个入口同时点同一 `photoId`：in-flight Set 挡住重复请求。

## Phase 6 详情 / 个人中心 / 性能

### 常规
- 详情展示标题、作者、标签、场景键、点赞。
- 「我的作品」列出当前用户发布（Mock 含「练习构图」及新发布）。
- 图片 `lazy-load`；主包仅首页，相机/社区/个人为分包。

### 弱网 / 并发
- 我的作品断网：读本地缓存并提示。
- 首页与详情来回切换，点赞状态与 `likedIds` 缓存一致。

## 接入真实云开发后的额外检查
- 上传云函数：`login` `getFeed` `getSceneRecommend` `getPhotoDetail` `getMyPosts` `publishPhoto` `toggleLike` `contentCheck`。
- 建集合：`users` `photos` `likes` `audit_logs`，索引见 `database/indexes.json`。
- `publishPhoto` / `contentCheck` 的 OpenAPI 权限包含内容安全接口。
- 真机：相机、定位、压缩、云存储上传、审核拒绝用例。
