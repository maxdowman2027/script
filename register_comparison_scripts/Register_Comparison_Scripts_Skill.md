# 寄存器比较脚本技能文档

## 概述

这些Python脚本用于比较不同版本的WiFi芯片（如RLS4.0和WiFi7）中的寄存器配置差异。它们提供了详细的数据分析、报告生成功能，帮助工程师识别和定位寄存器配置的变化，从而辅助硬件和固件的开发工作。

## 脚本功能

### 1. 核心比较脚本

#### `compare_registers.py`
**功能**：比较两个版本的寄存器配置差异
**特点**：
- 支持比较指定路径下的寄存器文件
- 自动识别相同寄存器值的差异
- 检测寄存器的增减情况
- 确定寄存器的实际使用值（优先使用修改值，未修改的使用默认值）
- 为每个寄存器文件生成详细的比较报告
- 支持比较多个寄存器文件

**使用方法**：
```python
# 修改脚本顶部的变量
version1_path = r"D:\reg\rls4"
version2_path = r"D:\reg\wifi7_new"
version1_name = "RLS4"
version2_name = "WiFi7"

# 直接运行脚本
python compare_registers.py
```

## 输出格式

### 比较报告
- 文件命名：`register_comparison_report_<filename>.txt`
- 报告内容包括：
  - 值不同的寄存器
  - 仅在版本1中存在的寄存器
  - 仅在版本2中存在的寄存器
  - 统计信息

## 输入文件格式

寄存器文件应为CSV格式，包含以下列：
- `Signal`：实际的寄存器名称
- `Default`：寄存器的默认值
- `Modify`：该寄存器被配置了的修改值，未被配置过的寄存器使用默认值

## 使用场景

1. **版本间寄存器比较**：比较不同版本的WiFi芯片寄存器配置差异
2. **硬件验证**：验证新硬件设计的寄存器配置是否正确
3. **固件开发**：辅助固件开发，定位寄存器配置问题
4. **批量数据分析**：处理大量寄存器数据，快速识别配置变化

## 注意事项

1. 确保输入文件路径正确且文件可读取
2. 脚本会自动读取指定路径下的所有列出的寄存器文件
3. 输出报告文件会覆盖已存在的同名文件
4. 脚本需要适当的权限来读写文件
