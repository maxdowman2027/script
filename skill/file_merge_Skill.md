# file_merge.py 脚本说明文档

## 脚本概述

file_merge.py 是一个用于合并多个 Excel 文件的 Python 脚本。它提供了强大的文件搜索和数据合并功能，支持通配符和正则表达式匹配文件夹和文件，能够将多个 Excel 文件的所有工作表合并到一个输出文件中，并保留原工作表信息。

## 主要功能

### 1. 灵活的搜索功能
- **根路径搜索**：在指定路径下递归查找目标文件夹
- **文件夹匹配**：支持通配符匹配（如 `*_result`）或正则表达式匹配
- **文件匹配**：支持指定 Excel 文件匹配模式（默认 `*.xlsx`）
- **搜索选项**：可配置是否使用正则表达式匹配

### 2. 智能合并功能
- **工作表合并**：将所有 Excel 文件的所有工作表合并到一个输出文件的单个工作表中
- **原工作表追踪**：新增一列标注每条数据的原工作表名称
- **表头处理**：仅保留一份合并后的表头（包含新增列）
- **数据验证**：检查输入路径和文件的有效性

### 3. 输出配置
- **输出文件**：可指定合并后的 Excel 文件路径
- **列名配置**：可自定义标注原工作表名称的列名（默认 `原工作表名称`）
- **文件格式**：仅处理 `.xlsx` 格式的 Excel 文件

## 配置方法

### 基本使用

```python
from file_merge import merge_all_sheets_to_one

merge_all_sheets_to_one(
    root_path=r"D:\data",
    folder_pattern="*_test",
    output_file=r"D:\results\merged_data.xlsx"
)
```

### 完整参数说明

```python
merge_all_sheets_to_one(
    root_path,              # 要搜索的根路径（必填）
    folder_pattern,         # 文件夹命名匹配规则（通配符/正则）（必填）
    output_file,            # 合并后的输出文件路径（必填）
    xlsx_pattern="*.xlsx",  # XLSX文件匹配规则（默认匹配所有XLSX）
    use_regex_folder=False, # 文件夹是否用正则匹配（默认 False）
    use_regex_xlsx=False,   # XLSX文件是否用正则匹配（默认 False）
    sheet_name_col="原工作表名称"  # 新增列的列名（标注原sheet名）
)
```

## 使用示例

### 示例 1：合并测试结果文件

```python
import os

# 配置参数
test_data_path = r"D:\chip_test\test_results"
merged_output_file = r"D:\chip_test\merged_results.xlsx"

    root_path=test_data_path,
    folder_pattern="*_result",
    output_file=merged_output_file,
    sheet_name_col="原始工作表"
)

print(f"合并完成！结果已保存到: {merged_output_file}")
```

### 示例 2：使用正则表达式匹配

```python
from file_merge import merge_all_sheets_to_one

merge_all_sheets_to_one(
    root_path=r"D:\data",
    folder_pattern=r"test_\d{4}",  # 匹配 test_2023, test_2024 等格式
    output_file=r"D:\results\merged_regex.xlsx",
    use_regex_folder=True,  # 启用正则表达式匹配文件夹
    use_regex_xlsx=True,    # 启用正则表达式匹配文件
    xlsx_pattern=r"result_\d{8}\.xlsx"  # 匹配 result_20230101.xlsx 格式
)
```

## 技术说明

### 依赖库
- **os**：操作系统相关操作
- **fnmatch**：文件名匹配（通配符）
- **re**：正则表达式处理
- **openpyxl**：Excel 文件读取和写入

### 执行流程
1. 验证输入路径的有效性
2. 搜索符合条件的文件夹
3. 收集目标文件夹中的 Excel 文件
4. 读取所有 Excel 文件的内容
5. 合并所有工作表数据
6. 添加原工作表名称列
7. 保存合并后的 Excel 文件

## 错误处理

### 常见错误
1. **路径不存在**：检查输入路径是否正确
2. **文件格式错误**：确保所有文件都是 `.xlsx` 格式
3. **权限问题**：确保对目标路径有写入权限
4. **数据格式问题**：处理包含特殊字符或格式的数据

### 错误信息
脚本会输出详细的错误信息，包括：
- 路径不存在的错误
- 文件读取错误
- 数据处理错误

- **场景**：从多个 Excel 文件中迁移数据到数据库
- **应用**：将多个源文件合并到一个文件中，便于后续处理

## 注意事项

### 1. 文件路径
- 使用原始字符串（r 前缀）避免转义字符问题
- 确保路径使用正确的分隔符（Windows 系统使用 `\`，其他系统使用 `/`）

### 2. 文件夹和文件匹配
- 通配符匹配使用 `fnmatch` 库，支持 `*` 和 `?` 通配符
- 正则表达式匹配使用 `re` 库，支持完整的正则表达式语法

### 3. 性能考虑
- 对于大量文件和数据，合并过程可能需要较长时间
- 确保有足够的磁盘空间保存输出文件
- 大型文件合并可能会消耗较多内存

### 4. 兼容性
- 只支持 `.xlsx` 格式的 Excel 文件
- 对于 `.xls` 格式的文件，需要先转换为 `.xlsx` 格式

## 故障排除

### 常见问题

1. **合并后数据丢失**
   - 检查文件夹和文件匹配规则是否正确
   - 确保源文件没有被其他程序锁定

2. **输出文件无法打开**
   - 检查是否有足够的磁盘空间
   - 确保对目标目录有写入权限

3. **原工作表名称列缺失**
   - 检查是否正确配置了 `sheet_name_col` 参数
   - 确保源文件的工作表名称不包含特殊字符

4. **合并速度慢**
   - 检查是否有不必要的文件被包含在搜索范围内
   - 考虑优化匹配规则，减少需要处理的文件数量
