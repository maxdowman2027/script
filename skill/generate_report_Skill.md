# generate_report.py 脚本说明文档

## 脚本概述

generate_report.py 是一个用于生成测试报告的 Python 脚本。它提供了强大的数据收集和报告生成功能，能够从测试数据中提取关键信息，并生成包含图表和统计数据的详细报告。

## 主要功能

### 1. 数据收集与分析
- **数据读取**：读取各种格式的测试数据文件（如 Excel、CSV）
- **数据清洗**：处理和清洗原始数据
- **统计分析**：计算关键指标的统计信息（如平均值、标准差）
- **异常检测**：识别数据中的异常值

### 2. 可视化报告
- **图表生成**：生成各种类型的图表（如折线图、柱状图、散点图）
- **图表标题**：为图表添加适当的标题和标签
- **图表格式**：支持多种图表格式（如 PNG、PDF）
- **图表尺寸**：可配置图表的尺寸和分辨率

### 3. 报告布局
- **报告结构**：生成包含封面、摘要、图表、表格的完整报告
- **内容组织**：按类别和子类别组织报告内容
- **格式化**：对报告内容进行格式化（如字体、颜色、样式）
- **导出格式**：支持导出为 HTML、PDF、Word 等格式

## 使用方法

### 基本使用

```python
from generate_report import generate_report

# 配置参数
config = {
    'input_file': r"D:\test_data.xlsx",
    'output_file': r"D:\report.html",
    'report_type': 'html',
    'title': '测试报告',
    'subtitle': 'WiFi 测试数据报告',
    'author': '测试团队',
    'date': '2023-12-01',
    'sections': [
        'summary',
        'statistics',
        'charts',
        'data_table'
    ]
}

# 生成报告
generate_report(config)
```

### 高级配置

```python
from generate_report import generate_report

config = {
    'input_file': r"D:\test_data.xlsx",
    'output_file': r"D:\report.pdf",
    'report_type': 'pdf',

    'subtitle': 'WiFi 测试数据报告',
    'author': '测试团队',
    'date': '2023-12-01',
    'sections': [
        'summary',
        'statistics',
        'charts',
        'data_table'
    ],
    'chart_types': [
        'line',
        'bar',
        'scatter'
    ],
    'colors': {
        'primary': '#007bff',
        'secondary': '#6c757d',
        'success': '#28a745',
        'danger': '#dc3545'
    },
    'font_size': 12,
    'page_size': 'A4',
    'margin': 20
}

generate_report(config)
```
