# check_excel_colors.py 脚本说明文档

## 脚本概述

check_excel_colors.py 是一个用于检查 Excel 文件中单元格填充色的 Python 脚本。它专门用于分析 WiFi 测试数据文件中的颜色标记，帮助测试团队快速识别不同 WiFi 格式的填充色方案。

## 主要功能

### 1. Excel 文件读取与解析
- **文件加载**：加载指定的 Excel 文件
- **工作表解析**：解析 Excel 文件中的工作表
- **列定位**：定位 'wifi_format' 列的位置
- **数据提取**：提取 'wifi_format' 列的数据和填充色

### 2. 填充色分析
- **颜色统计**：统计不同 WiFi 格式的填充色
- **颜色编码**：提取填充色的 RGB 编码
- **格式计数**：统计每种 WiFi 格式的行数
- **颜色关联**：建立 WiFi 格式与填充色的关联

### 3. 结果输出
- **控制台输出**：详细的填充色分析结果
- **结果验证**：验证填充色是否符合预期
- **问题检测**：检测填充色使用不当的问题

## 使用方法

### 基本使用

```python
from check_excel_colors import check_excel_colors

# 检查 Excel 文件中的填充色
file_path = r"D:\test_data.xlsx"
sheet_name = "Sheet1"
success = check_excel_colors(file_path, sheet_name)

if success:
    print("检查完成")
else:
    print("检查失败")
```

### 高级配置

```python
from check_excel_colors import check_excel_colors

# 检查 Excel 文件中的填充色
file_path = r"D:\test_data.xlsx"
sheet_name = "Results"

# 预期的填充色方案
expected_colors = {
    'he_20m': 'FF0000',  # 红色
    'he_40m': '00FF00',  # 绿色
    'he_80m': '0000FF',  # 蓝色
    'he_160m': 'FFFF00'  # 黄色
}

success = check_excel_colors(file_path, sheet_name, expected_colors)

if success:
    print("填充色符合预期")
else:
    print("填充色不符合预期")
```

- **列要求**：工作表必须包含 'wifi_format' 列
- **填充色**：填充色必须是 RGB 编码

## 注意事项

### 1. 填充色编码
- Excel 使用 RGB 颜色编码，脚本会提取填充色的 RGB 编码
- 脚本会移除颜色编码前的 '00' 前缀

### 2. 空值处理
- 脚本会忽略 'wifi_format' 列为空的行
- 空值不会计入统计

### 3. 填充色判断
- 只有非白色填充色会被统计
- 白色填充色（'00000000'）会被忽略

## 故障排除

### 常见问题

1. **文件无法加载**
   - 检查文件路径是否正确
   - 确保文件格式正确
   - 检查文件权限

2. **工作表不存在**
   - 检查工作表名称是否正确
   - 确保工作表存在于文件中

3. **列名不匹配**
   - 确保列名的拼写和大小写正确
   - 检查是否有多余的空格或字符

4. **填充色统计错误**
   - 检查填充色是否使用了正确的 RGB 编码
   - 确保填充色不是白色
