# validate_conversion.py 脚本说明文档

## 脚本概述

validate_conversion.py 是一个用于验证 DAC（数模转换器）转换结果的 Python 脚本。它提供了强大的数值验证功能，能够检查转换结果是否符合预期的数值范围。

## 主要功能

### 1. 数据读取与解析
- **文件读取**：读取 CSV 格式的转换结果文件
- **数据解析**：解析包含 DAC 转换结果的列
- **值提取**：提取 DAC 转换结果的数值
- **数据类型检查**：检查值的数据类型是否符合预期

### 2. 数值验证
- **负数值检查**：检查是否包含负数值
- **范围验证**：验证值是否在预期的数值范围内
- **位宽检查**：检查值是否符合指定位宽的要求
- **数据完整性检查**：检查数据是否完整

### 3. 统计分析
- **行统计**：统计总数据行数、有效行数和错误行数
- **数值分布**：统计包含负值的行数
- **范围统计**：统计值范围在有效范围内的行数
- **误差分析**：分析转换结果的误差情况

## 使用方法

### 基本使用

```python
from validate_conversion import validate_conversion

# 验证 DAC 转换结果
csv_file = r"D:\test_data\waveform_decimal.csv"
validate_conversion(csv_file)
```

### 高级配置

```python
from validate_conversion import validate_conversion

# 验证 DAC 转换结果
csv_file = r"D:\test_data\waveform_decimal.csv"

# 预期的数值范围（12位有符号整数）
expected_range = (-2048, 2047)

validate_conversion(csv_file, expected_range)
```

## 输入文件要求

### 文件格式
- **CSV 文件**：必须是逗号分隔的文本文件
- **编码**：建议使用 UTF-8 编码
- **列名**：文件必须包含以下列：
  - 'dac_i_ch0[11:0]'：通道 0 的 I 路 DAC 转换结果
  - 'dac_q_ch0[11:0]'：通道 0 的 Q 路 DAC 转换结果
  - 'dac_vliad_ch0[0:0]'：通道 0 的 VL 路 DAC 转换结果（可选）
  - 'dac_i_ch1[11:0]'：通道 1 的 I 路 DAC 转换结果（可选）
  - 'dac_q_ch1[11:0]'：通道 1 的 Q 路 DAC 转换结果（可选）

### 文件命名
- 文件命名无特殊要求，但建议使用有意义的文件名
- 文件名应避免包含特殊字符

## 输出结果

### 1. 控制台输出
- **转换结果统计**：显示总数据行数、有效行数、错误行数
- **负数值统计**：显示包含负值的行数
- **范围验证统计**：显示值范围在有效范围内的行数
- **验证结果**：总结验证过程中发现的问题

### 2. 验证报告
- **成功**：所有值均在预期范围内

## 注意事项

### 1. 位宽验证
- 脚本验证的是 12 位有符号整数范围（-2048 至 2047）
- 如需验证其他位宽，需要修改脚本
- 位宽范围会影响验证结果的准确性

### 2. 负数值检查
- 脚本专门检查负值，这对于有符号数的 DAC 转换结果很重要
- 负值可能会导致信号失真或其他问题

### 3. 数据完整性
- 脚本会检查所有需要转换的列
- 任何一列的值无效都会导致该行数据被标记为错误
