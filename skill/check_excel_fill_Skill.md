# check_excel_fill.py 脚本说明文档

## 脚本概述

check_excel_fill.py 是一个用于检查 Excel 文件中 EVM（误差向量幅度）相关列填充色的 Python 脚本。它能够识别 Excel 文件中 EVM 相关列的位置，并检查这些列是否已应用填充色。

## 主要功能

### 1. Excel 文件读取与解析
- **文件加载**：加载指定的 Excel 文件
- **工作表解析**：解析 Excel 文件中的活动工作表
- **列定位**：定位 'evm_old', 'evm_new', 'evm_diff' 等 EVM 相关列的位置
- **数据提取**：提取 EVM 相关列的填充色信息

### 2. 填充色检查
- **填充色识别**：识别单元格是否已应用填充色
- **颜色编码**：提取填充色的 RGB 编码
- **位置信息**：记录已应用填充色的单元格位置
- **结果输出**：输出填充色检查结果

### 3. 验证功能
- **填充色验证**：验证 EVM 相关列是否已应用填充色
- **完整性检查**：检查填充色是否覆盖所有相关列
- **一致性检查**：检查填充色是否符合预期的颜色方案

## 使用方法

### 基本使用

```python
from check_excel_fill import check_fill_color

# 检查 Excel 文件中的填充色
excel_file = r"D:\test_data.xlsx"
check_fill_color(excel_file)
```

### 高级配置

```python
from check_excel_fill import check_fill_color

# 检查 Excel 文件中的填充色
excel_file = r"D:\test_data.xlsx"

# 预期的填充色方案
expected_colors = {
    'evm_old': 'FF0000',  # 红色
    'evm_new': '00FF00',  # 绿色
    'evm_diff': '0000FF'  # 蓝色
}

check_fill_color(excel_file, expected_colors)
```

## 输入文件要求

### 文件格式
- **Excel 文件**：必须是 `.xlsx` 格式的 Excel 文件
- **工作表**：文件必须包含活动工作表
- **列要求**：工作表必须包含 EVM 相关列（如 'evm_old', 'evm_new', 'evm_diff'）
- **填充色**：填充色必须是 RGB 编码

### 文件命名
- 文件命名无特殊要求，但建议使用有意义的文件名
- 文件名应避免包含特殊字符

## 注意事项

### 1. 填充色识别
- 脚本只检查 'evm_old', 'evm_new', 'evm_diff' 等 EVM 相关列
- 其他列的填充色不会被检查

### 2. 填充色编码
- Excel 使用 RGB 颜色编码，脚本会提取填充色的 RGB 编码
- 脚本会检查填充色的 index 是否为 '00000000'（无填充色）

### 3. 工作表限制
- 脚本只检查活动工作表
- 不支持检查多个工作表

## 故障排除

### 常见问题

1. **文件无法加载**
   - 检查文件路径是否正确
   - 确保文件格式正确
   - 检查文件权限

2. **EVM 相关列未找到**
   - 确保工作表包含 'evm_old', 'evm_new', 'evm_diff' 等列
   - 检查列名的拼写是否正确

3. **填充色未应用**
   - 检查是否已正确应用填充色
   - 确保填充色未被意外删除
   - 尝试重新应用填充色

4. **填充色不符合预期**
   - 检查填充色是否符合预期的颜色方案
   - 尝试使用其他颜色方案
   - 确保填充色的 RGB 编码正确
