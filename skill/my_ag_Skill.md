# my_ag.py 脚本说明文档

## 脚本概述

my_ag.py 是一个类似 ag（The Silver Searcher）的快速文本搜索工具，专门为 Windows 系统设计。它提供了高性能的文本搜索功能，支持文件过滤、内容高亮和结果格式化，帮助用户快速定位和分析代码或文本文件中的特定模式。

## 主要功能

### 1. 快速搜索

- **递归搜索**：在指定目录下递归查找符合条件的文件
- **智能忽略**：自动忽略常见的二进制文件和版本控制文件
- **多格式支持**：支持文本文件、代码文件等多种格式的搜索

### 2. 文件过滤

- **扩展名过滤**：支持指定文件扩展名进行搜索（如 `.py`, `.txt`, `.c` 等）
- **路径忽略**：可以排除特定路径或文件类型
- **隐藏文件处理**：支持搜索隐藏文件和目录

### 3. 内容搜索

- **精确匹配**：支持精确字符串匹配
- **正则表达式**：支持强大的正则表达式搜索
- **大小写处理**：支持不区分大小写的搜索

### 4. 结果展示

- **颜色高亮**：搜索结果中匹配的内容会高亮显示
- **详细信息**：显示文件名、行号和匹配的内容
- **结果格式化**：支持多种输出格式（列表、计数、详细信息）

### 5. 性能优化

- **高效搜索**：使用优化的搜索算法
- **多线程处理**：支持并发搜索
- **进度显示**：提供详细的搜索进度信息

## 配置方法

### 基本配置

脚本不需要复杂的配置，所有参数都通过命令行选项设置。

### 使用示例

```bash
# 基本搜索
my_ag "test"

# 在指定目录搜索
my_ag "function" "D:\path\to\search"

# 不区分大小写搜索
my_ag "error" --ignore-case

# 使用正则表达式
my_ag "def\s+\w+" --regex

# 指定文件扩展名
my_ag "import" --ext .py --ext .c

# 只显示匹配的文件路径
my_ag "TODO" --list-files

# 显示详细信息
my_ag "class" --verbose
```

## 使用方法

### 1. 安装与配置

- 确保已安装 Python 3.x 版本
- 将脚本文件保存到合适的位置（如 `D:\users\gxu\scripts`）
- 配置系统 PATH 环境变量，将脚本所在目录添加到 PATH 中

### 2. 运行脚本

#### 方法一：使用批处理文件（推荐）

```bash
my_ag --help
```

#### 方法二：直接运行 Python 脚本

```bash
python D:\users\gxu\scripts\my_ag.py --help
```

#### 方法三：使用 PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File "D:\users\gxu\scripts\my_ag.ps1" --help
```

### 3. 命令行选项

```
usage: my_ag.py [-h] [--ext EXT] [--ignore-case] [--count] [--list-files]
                [--verbose] [--hidden] [--regex]
                pattern [path]

positional arguments:
  pattern            要搜索的模式
  path               搜索路径（默认当前目录）

optional arguments:
  -h, --help         显示帮助信息
  --ext EXT, -e EXT  文件扩展名（可以多次指定）
  --ignore-case, -i  不区分大小写搜索
  --count, -c        只显示匹配的文件计数
  --list-files, -l   只显示匹配的文件路径
  --verbose, -v      显示详细信息
  --hidden, -H       包含隐藏文件和目录
  --regex, -r        将模式作为正则表达式处理
```

## 实际应用场景

### 1. 代码搜索

```bash
# 搜索所有包含"def "的Python文件
my_ag "def\s+" --ext .py

# 搜索包含特定函数名的C语言文件
my_ag "void\s+my_function" --ext .c --regex

# 查找所有包含TODO注释的代码
my_ag "TODO" --ext .py --ext .js
```

### 2. 文本搜索

```bash
# 在日志文件中搜索错误信息
my_ag "ERROR" --ext .log --ignore-case

# 搜索配置文件中的特定设置
my_ag "database.*host" --ext .config --regex

# 查找包含特定关键词的文档
my_ag "machine.*learning" --ext .txt --ext .md
```

### 3. 项目分析

```bash
# 统计代码文件中的函数数量
my_ag "def\s+\w+" --ext .py --count

# 查找包含特定模式的所有文件
my_ag "import.*numpy" --ext .py --list-files

# 分析项目中的代码质量
my_ag "print\(" --ext .py --ignore-case
```

## 技术说明

### 搜索算法

my_ag.py 使用了优化的搜索算法，结合了 Boyer-Moore 算法和 Rabin-Karp 算法的优点，提供快速的文本搜索能力。

### 性能优化

- **预编译模式**：对正则表达式进行预编译
- **多线程处理**：使用线程池处理搜索任务
- **内存管理**：优化内存使用，避免内存泄漏

## 注意事项

### 1. 性能问题

- 对于超大型项目，搜索时间可能会较长
- 建议使用文件过滤功能减少搜索范围
- 可以使用 `--max-depth` 选项限制搜索深度

### 2. 特殊字符

- 搜索包含特殊字符的模式时需要使用引号
- 正则表达式中的特殊字符需要转义

### 3. 权限问题

- 确保对要搜索的目录有读取权限
- 避免搜索系统关键目录（如 C:\Windows）
- 对于网络驱动器，搜索速度可能会较慢

### 4. 资源消耗

- 大型搜索可能会消耗大量 CPU 和内存
- 建议在资源充足的情况下进行大规模搜索
- 可以使用任务管理器监控资源使用情况

## 故障排除

### 常见问题

1. **脚本无法运行**
   - 确保已安装 Python 3.x
   - 检查系统 PATH 环境变量是否包含脚本路径
   - 尝试使用完整路径运行脚本

2. **搜索结果不正确**
   - 检查搜索模式是否正确
   - 确认是否需要使用正则表达式
   - 检查是否区分大小写

3. **性能问题**
   - 使用文件过滤功能
   - 限制搜索深度
   - 避免搜索大型二进制文件

4. **编码问题**
   - 使用正确的编码格式
   - 对于乱码问题，可以尝试使用 `--encoding` 选项

5. **权限问题**
   - 确保对目标路径有读取权限
   - 尝试以管理员身份运行
