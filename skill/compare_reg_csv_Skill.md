# compare_reg_csv.py 脚本说明文档

## 脚本概述

compare_reg_csv.py 是一个用于比较两个寄存器配置 CSV 文件的 Python 脚本。它提供了强大的寄存器值提取和比较功能，能够识别两个寄存器配置之间的差异。

## 主要功能

### 1. 寄存器值提取
- **文件读取**：读取两个寄存器配置 CSV 文件
- **值提取**：从 CSV 文件中提取寄存器的实际值（优先使用 Modify 值，其次使用 Default 值）
- **数据类型转换**：将 Signal 列转换为字符串类型，确保比较的准确性
- **数据清洗**：处理 NaN 值和空字符串

### 2. 寄存器比较
- **比较逻辑**：比较两个寄存器配置的差异
- **差异报告**：输出详细的差异信息（新增、移除、修改的寄存器）
- **值变化**：显示寄存器值的变化
- **详细信息**：包括寄存器名称、旧值和新值

### 3. 输出格式
- **控制台输出**：详细的差异报告（彩色显示）
- **文本文件**：将比较结果保存到文本文件中
- **格式控制**：通过参数控制输出格式（如是否显示所有差异）

## 使用方法

### 基本使用

```python
# 导入模块
from compare_reg_csv import compare_csv_files

# 文件路径
file1 = r"D:\path\to\file1.csv"
file2 = r"D:\path\to\file2.csv"
filename = "register_comparison"
reg_prefix = "PHY_"

# 比较文件
compare_csv_files(file1, file2, filename, reg_prefix)
```

### 完整参数说明

```python
compare_csv_files(
    file1,          # 第一个文件的路径
    file2,          # 第二个文件的路径
    filename,       # 比较结果的文件名（不含扩展名）
    reg_prefix=""   # 寄存器名称的前缀（可选，用于过滤）
)
```

## 输入文件要求

### 文件格式
- **CSV 文件**：必须是逗号分隔的文本文件
- **编码**：建议使用 UTF-8 编码（含 BOM）
- **列名**：文件必须包含以下列：
  - 'Signal'：寄存器名称
  - 'Default'：寄存器的默认值
  - 'Modify'：寄存器的修改值（可选）

### 文件命名
- 文件命名无特殊要求，但建议使用有意义的文件名
- 文件名应避免包含特殊字符

## 输出结果

### 1. 控制台输出
- **彩色显示**：使用不同颜色显示差异类型（新增：绿色，移除：红色，修改：黄色）
- **详细信息**：
  - 新增的寄存器：显示寄存器名称和值
  - 移除的寄存器：显示寄存器名称和值
  - 修改的寄存器：显示寄存器名称、旧值和新值
- **统计信息**：显示差异的总数量

### 2. 文本文件
- **输出文件名**：`<filename>_diff.txt`
- **输出格式**：包含与控制台输出相同的信息
- **文件位置**：与脚本同级目录

### 常见错误
1. **文件找不到**：检查文件路径是否正确
2. **列名缺失**：确保文件包含 'Signal' 和 'Default' 列
3. **权限问题**：确保对目标目录有写入权限
4. **编码错误**：文件编码不正确

## 性能优化

### 1. 处理大型文件
- **分批次处理**：对于大型文件，分批次读取和处理
- **内存优化**：使用 pandas 的逐行处理功能
- **并行处理**：可考虑使用多线程处理

### 2. 优化输出
- **过滤结果**：只显示感兴趣的寄存器
- **格式化输出**：优化输出格式，提高可读性
- **压缩结果**：对大量差异进行总结

## 注意事项

### 1. 寄存器值比较
- 脚本优先使用 Modify 值，如果 Modify 值为空或不存在，则使用 Default 值
- 空字符串和 NaN 值会被处理为相同的值

### 2. 输出格式
- 控制台输出使用 ANSI 颜色，可能在某些环境中不显示
- 文本文件输出不包含颜色信息

### 3. 文件编码
- 建议使用 UTF-8 编码的文件
- 如果文件编码不同，可能会出现乱码问题
