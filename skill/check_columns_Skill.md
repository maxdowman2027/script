# check_columns.py 脚本说明文档

## 脚本概述

check_columns.py 是一个用于检查 Excel 文件中不同工作表列顺序一致性的 Python 脚本。它能够比较 Excel 文件中不同工作表的列顺序，并输出详细的比较结果。

## 主要功能

### 1. Excel 文件读取与解析
- **文件加载**：加载指定的 Excel 文件
- **工作表解析**：解析 Excel 文件中的所有工作表
- **列提取**：提取每个工作表的列名和顺序
- **数据结构分析**：分析 Excel 文件的结构

### 2. 列顺序比较
- **列名比较**：比较不同工作表的列名是否一致
- **顺序比较**：比较列顺序是否相同
- **差异识别**：识别列顺序的差异
- **详细报告**：输出列顺序比较的详细报告

### 3. 结果输出
- **控制台输出**：详细的列顺序比较结果
- **可视化展示**：以列表形式显示各工作表的列顺序
- **差异高亮**：高亮显示列顺序的差异
- **完整性检查**：检查所有工作表的列顺序是否一致

## 使用方法

### 基本使用

```python
from check_columns import check_columns

# 检查 Excel 文件中不同工作表的列顺序
file_path = r"D:\test_data.xlsx"
check_columns(file_path)
```

### 高级配置

```python
from check_columns import check_columns

# 检查 Excel 文件中不同工作表的列顺序
file_path = r"D:\test_data.xlsx"

# 指定要比较的工作表名称
sheets_to_compare = ["channel11_BCC", "channel5180_LDPC"]

check_columns(file_path, sheets_to_compare)
```

## 输入文件要求

### 文件格式
- **Excel 文件**：必须是 `.xlsx` 格式的 Excel 文件
- **工作表**：文件必须包含至少两个工作表用于比较
- **列要求**：工作表必须包含数据列
- **数据类型**：列名应为字符串类型

### 文件命名
- 文件命名无特殊要求，但建议使用有意义的文件名
- 文件名应避免包含特殊字符

## 输出结果

### 1. 控制台输出
- **工作表信息**：显示每个工作表的列顺序
- **列顺序**：以编号形式显示列顺序
- **比较结果**：显示列顺序的差异
- **总结信息**：输出比较结果的总结

### 2. 比较结果
- **完全一致**：所有工作表的列顺序完全一致
- **部分一致**：部分工作表的列顺序一致
- **不一致**：所有工作表的列顺序都不一致
