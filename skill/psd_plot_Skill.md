# psd_plot.py 脚本说明文档

## 脚本概述

psd_plot.py 是一个用于绘制功率谱密度（PSD）图表的 Python 脚本。它提供了强大的 PSD 计算和可视化功能，能够分析 WiFi 测试数据中的信号特征。

## 主要功能

### 1. 数据读取与处理
- **文件读取**：读取 CSV 格式的测试数据文件
- **数据清洗**：处理和清洗原始数据
- **路径规范化**：自动处理不同操作系统的路径分隔符
- **工作目录配置**：支持设置工作目录

### 2. PSD 计算
- **PSD 计算**：使用 Welch 方法计算功率谱密度
- **参数配置**：可配置采样频率、窗口类型、重叠率等参数
- **频率范围**：支持自定义频率范围
- **单位转换**：计算并显示 dBm/Hz 单位的 PSD

### 3. 可视化分析
- **图表生成**：生成 PSD 图表
- **图表标题**：为图表添加适当的标题和标签
- **图表格式**：支持多种图表格式（如 PNG、PDF）
- **图表尺寸**：可配置图表的尺寸和分辨率

### 4. 杂散检测
- **杂散检测**：自动检测并标记杂散信号
- **阈值配置**：可配置杂散检测的阈值
- **报告生成**：生成包含杂散信息的报告

## 使用方法

### 基本使用

```python
from psd_plot import calculate_and_plot_psd

# 配置参数
config = {
    'work_dir': r"D:\users\gxu\temp\260327\hesu_nss2",
    'csv_files': ['test_data.csv'],
    'fs': 80,  # 采样频率 (MHz)
    'spur_threshold': 18,  # 杂散检测阈值 (dB)
    'output_dir': 'result'  # 输出目录
}

# 计算并绘制 PSD
calculate_and_plot_psd(config)
```

### 高级配置

```python
from psd_plot import calculate_and_plot_psd

config = {
    'work_dir': r"D:\test_data",
    'csv_files': ['data1.csv', 'data2.csv'],
    'fs': 80,
    'spur_threshold': 18,
    'output_dir': 'results',
    'window_type': 'hann',  # 窗口类型
    'window_length': 1024,  # 窗口长度
    'overlap': 0.5,  # 重叠率
    'freq_range': [0, 40],  # 频率范围 (MHz)
    'plot_format': 'pdf',  # 图表格式
    'dpi': 300,  # 图表分辨率
    'color_map': 'viridis'  # 颜色映射
}

calculate_and_plot_psd(config)
```

## 输入文件要求

### 文件格式
- **CSV 文件**：必须是逗号分隔的文本文件
- **编码**：建议使用 UTF-8 编码
- **列名**：文件必须包含以下列：
  - 'phy_mode'：物理模式（如 'he', 'erp', '11b' 等）
  - 'channel'：信道号
  - 'frequency'：频率（MHz）
  - 'diff_pwr'：功率差异（dB）
  - 'pwr'：功率（dBm）

### 文件命名
- 文件命名无特殊要求，但建议使用有意义的文件名
- 文件名应避免包含特殊字符

## 注意事项

### 1. 频率单位
- 脚本使用的频率单位是 MHz（兆赫兹）
- 采样频率需要根据实际信号进行配置

### 2. 窗口类型
- 支持多种窗口类型（如 'hann', 'hamming', 'blackman' 等）
- 窗口类型会影响 PSD 计算的分辨率和旁瓣衰减

### 3. 重叠率
- 重叠率会影响 PSD 计算的频率分辨率和方差
- 一般建议使用 50% 的重叠率

### 4. 杂散检测
- 杂散检测阈值需要根据实际信号进行配置
- 阈值设置过高会漏检杂散，设置过低会误检

## 故障排除

### 常见问题

1. **图表无法生成**
   - 检查输出目录的权限
   - 确保输出目录存在
   - 检查图表格式配置是否正确

2. **PSD 计算错误**
   - 检查采样频率配置是否正确
   - 确保数据格式正确
   - 尝试调整窗口参数

3. **杂散检测不准确**
   - 调整杂散检测阈值
   - 检查数据质量
   - 尝试使用其他检测方法

4. **性能问题**
   - 考虑分批次处理数据
   - 优化图表生成参数
   - 定期清理临时文件
