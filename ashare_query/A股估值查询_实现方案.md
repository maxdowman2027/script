# A 股全市场 PE / 股息率查询工具 — 完整实现方案

本文档描述 Windows 桌面程序「A 股估值查询」的完整方案、分步实现、已落地内容与实现方式。

- 程序目录：`ashare_query/`
- 主程序：`ashare_pe_yield.py`
- 启动方式：双击 `启动A股查询.bat`，或 `python ashare_pe_yield.py`
- 数据源：东方财富公开行情接口（无需 Token）
- 目标：自动查询当前全部 A 股最新信息，列出每家公司的 PE 与股息率

---

## 1. 目标与范围

### 1.1 要解决的问题

在 Windows 上提供一个可双击运行的软件，启动后自动拉取沪深京全部 A 股最新行情，以表格列出每家上市公司的估值指标，并支持筛选、排序、定时刷新和导出。

### 1.2 覆盖范围

| 市场 | 代码特征 | 东方财富 `fs` 片段 |
|------|----------|-------------------|
| 上证主板 | `60xxxx` / `601` / `603` / `605` | `m:1+t:2` |
| 科创板 | `688` / `689` | `m:1+t:23` |
| 深证主板 | `00xxxx` | `m:0+t:6` |
| 创业板 | `30xxxx` | `m:0+t:80` |
| 北交所 | `8/4/9` 开头 | `m:0+t:81+s:2048` |

含 ST、未盈利、尚未分红的公司。无数据的格子显示 `-`，不伪造 0。

### 1.3 字段口径

| 界面列 | 内部键 | 东方财富字段 | 含义 |
|--------|--------|--------------|------|
| 代码 | `code` | `f12` | 6 位证券代码 |
| 名称 | `name` | `f14` | 证券简称 |
| 板块 | `board` | 由代码前缀推导 | 上证主板 / 科创板 / 深证主板 / 创业板 / 北交所 |
| 行业 | `industry` | `f100` | 东财行业 |
| 最新价 | `price` | `f2` | 最新成交价 |
| 涨跌幅% | `chg_pct` | `f3` | 涨跌幅，单位 % |
| PE(动态) | `pe_dyn` | `f9` | 滚动预测市盈率 |
| PE(TTM) | `pe_ttm` | `f115` | 近 12 个月市盈率（筛选/中位数主字段） |
| PE(静) | `pe_lyr` | `f114` | 上年年报市盈率 |
| 股息率% | `div_yield` | `f133` | 股息率（东财 TTM 口径） |
| 市净率 | `pb` | `f23` | PB |
| 总市值(亿) | `mcap` | `f20` | 元 → 除以 `1e8` 转为亿元 |

筛选 PE 时优先用 `PE(TTM)`，缺失则回退 `PE(动态)`。

### 1.4 第一版要做 / 不做

**要做**

- 启动即自动拉全市场
- 搜索、板块、PE 区间、最低股息率、排除亏损、仅有分红
- 点表头排序、双击打开东财行情页
- 导出当前筛选结果（CSV / Excel）
- 可选定时自动刷新；联网失败回退本地缓存

**第一版不做**

- 不接 Tushare 等付费 Token
- 不做交易、回测、荐股
- 不打包独立 `.exe`（列为后续）
- 不把本工具当作投资建议

## 2. 总体架构

```text
启动A股查询.bat
        │
        ▼
ashare_pe_yield.py
  ├─ 数据层  fetch_ashare_quotes()     东方财富 clist API，分页 + 4 线程
  ├─ 缓存层  cache/last_quote.json     上次成功快照，断网回退
  ├─ 过滤层  apply_filter()            搜索 / 板块 / PE / 股息率
  └─ 界面层  tkinter Treeview          表格 + 导出 + 自动刷新
```

| 模块 | 职责 | 关键函数 / 类 |
|------|------|----------------|
| 行情采集 | 分页、多域名容错、字段映射 | `_fetch_page`, `fetch_ashare_quotes`, `classify_row` |
| 本地缓存 | 成功落盘；失败读盘 | `save_cache`, `load_cache` |
| 业务过滤 | 内存筛选，不重复联网 | `AShareApp.apply_filter` |
| 桌面 UI | 后台拉数，主线程改表 | `AShareApp` |
| 导出 | 当前 `view_rows` → 文件 | `export_table` |

**线程模型**

- Tk 主线程只负责界面
- 刷新在 `threading.Thread(daemon=True)` 中执行
- 进度与结果通过 `root.after(0, ...)` 回到主线程
- 并发拉页用 `ThreadPoolExecutor(max_workers=4)`，每页独立 `requests.Session`

**依赖**

- Python 3.7+（需带 tkinter，Windows 官方安装包默认包含）
- `requests`：HTTP
- `openpyxl`：仅导出 Excel 时需要
- 不依赖 akshare / pandas，降低安装成本

## 3. 分步实现方案

### 步骤 1：确定需求与字段口径

把「全部公司的 PE 与股息率」定义成可验收的字段表（见 §1.3），并确认：

- 全市场约 5900 家，不是成分股子集
- PE 同时提供动态 / TTM / 静态，避免口径争议
- 股息率用东财 `f133`，与行情中心列表一致

**状态：已完成。**

### 步骤 2：搭 Windows 工程骨架

目录：

```text
ashare_query/
  ashare_pe_yield.py              # 主程序（采集 + UI）
  启动A股查询.bat                  # 双击入口
  requirements.txt                # requests、openpyxl
  A股估值查询_实现方案.md          # 本文档
  cache/                          # 运行后生成，不入库
```

实现要点：

1. bat 先 `chcp 65001`、`cd /d "%~dp0"`，再调用 `python ashare_pe_yield.py`
2. 失败时提示 `pip install -r requirements.txt` 并 `pause`，避免窗口闪退
3. `_enable_windows_dpi()`：`SetProcessDpiAwareness(1)`，高分屏不糊
4. 缺 tkinter / requests 时打印明确错误并退出

**状态：已完成。**

### 步骤 3：打通东方财富行情接口

接口：

```text
GET https://push2.eastmoney.com/api/qt/clist/get
```

关键参数：

| 参数 | 取值 | 作用 |
|------|------|------|
| `fs` | `m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23,m:0+t:81+s:2048` | 沪深京 A 股 |
| `fields` | `f12,f13,f14,f2,f3,f9,f114,f115,f133,f23,f20,f8,f100` | 代码到股息率 |
| `pn` / `pz` | 页码 / 每页条数 | 实测 `pz` 上限 **100** |
| `fltt` | `2` | 返回浮点，不要定点数 |
| `fid` | `f12` | 按代码排序，分页稳定 |
| `ut` | 东财公共客户端标识 | 与网页行情相同 |

请求头带浏览器 `User-Agent` 和 `Referer: https://quote.eastmoney.com/center/gridlist.html`。

实现函数 `_fetch_page()`：解析 `data.total` 与 `data.diff`；`diff` 可能是 list 或 dict，dict 时取 `values()`。空值 `"-"` 在后续 `to_float()` 转为 `None`。

**状态：已完成。** 单页已核对：`f115` 为 PE(TTM)，`f133` 为股息率。

### 步骤 4：全市场分页 + 并发 + 容错

约束：全市场约 5905 条，每页最多 100 条 → 约 60 页。串行过慢，故并发。

实现方式（`fetch_ashare_quotes`）：

1. 主备域名依次尝试：
   - `https://push2.eastmoney.com/api/qt/clist/get`
   - `https://82.push2.eastmoney.com/api/qt/clist/get`
   - `https://push2delay.eastmoney.com/api/qt/clist/get`
2. 先拉第 1 页，用实际返回条数计算总页数（不假设 `pz=5000` 能一次拿全）
3. 第 2 页起用 4 线程并行；每线程新建 `Session`（`requests.Session` 非线程安全）
4. 结果按页号 `1..N` 拼接，避免 `as_completed` 乱序丢页
5. 按股票代码去重，再按代码排序
6. `progress_cb(done, total)` 更新状态栏
7. 单次超时 20 秒；当前域名失败换下一个；全部失败抛 `RuntimeError`

**状态：已完成。** 实测一次拉全 **5905** 家（见 §5）。

### 步骤 5：字段清洗与板块分类

`classify_row(raw)` 把东财 JSON 收成内部字典：

- `to_float()`：`None` / `""` / `"-"` → Python `None`
- 代码 `zfill(6)`
- 总市值 `f20 / 1e8`
- 板块 `board_of(code)`：
  - `688`/`689` → 科创板
  - 其余 `6` 开头 → 上证主板
  - `30` → 创业板
  - `00` → 深证主板
  - `8`/`4`/`9` → 北交所
- 行情页 `quote_url(code)`：`6`→`sh`，`8/4/9`→`bj`，其余→`sz`

亏损公司 PE 可为负数，界面照实显示，不改成 `-`（仅接口返回 `-` 时才显示 `-`）。

**状态：已完成。**

### 步骤 6：本地缓存

路径：`ashare_query/cache/last_quote.json`（gitignore，不入库）。

- 在线成功：`save_cache(rows, fetched_at)` 写入时间戳 + 全部行
- 在线失败：`load_cache()`；有缓存则填表，状态栏加「（缓存）」
- 无缓存：弹错误框
- 缓存读写异常不影响主流程（`try/except` 吞掉写盘失败）

**状态：已完成。**

### 步骤 7：桌面主界面

用系统自带 tkinter / ttk，不另装 GUI 库。

布局：

```text
┌──────────────────────────────────────────────────────────┐
│ 标题：A股全市场估值          [刷新最新] [导出Excel] [导出CSV] │
├──────────────────────────────────────────────────────────┤
│ 搜索  板块  PE(TTM)区间  股息率≥  排除亏损  仅有分红  筛选/清空 │
│ 自动刷新 + 间隔(秒)     操作说明                             │
├──────────────────────────────────────────────────────────┤
│ Treeview 表格（全市场行，可滚动、点表头排序）                 │
├──────────────────────────────────────────────────────────┤
│ 状态：拉取进度    显示数/总数  PE中位数  股息率中位数  更新时间 │
└──────────────────────────────────────────────────────────┘
```

实现要点：

- 默认窗口 1280×760，最小 980×560
- 字体 Microsoft YaHei UI
- 涨红跌绿（A 股习惯），斑马纹
- ttk 使用 `clam` 主题：Windows Vista 主题下表头设白字会看不见
- 快捷键：F5 刷新，Ctrl+C 复制选中行
- 双击 / 右键「打开行情页」调用系统浏览器

**状态：已完成。**

### 步骤 8：后台刷新，界面不卡死

`refresh_async()`：

1. `self.fetching` 防重入
2. 按钮改为「刷新中...」并禁用
3. 后台线程调用 `fetch_ashare_quotes`
4. 成功：`_on_fetch_ok` → 写入 `all_rows` → `apply_filter()`
5. 失败：`_on_fetch_fail` → 尝试缓存
6. 启动后 `root.after(200, self.refresh_async)`，打开即自动查询

自动刷新：勾选后按 30/60/120/300 秒循环；间隔下限 15 秒，避免打爆接口。关闭窗口时 `after_cancel` 定时器。

**状态：已完成。**

### 步骤 9：筛选、排序、汇总

全量在内存 `all_rows`，筛完得到 `view_rows` 再刷新 Treeview，不重复联网。

| 条件 | 规则 |
|------|------|
| 搜索 | 代码、名称、行业包含关键字；输入防抖 280 ms |
| 板块 | 下拉：全部 / 五大板块 |
| PE(TTM) 区间 | 缺 TTM 用动态 PE；缺数据则排除 |
| 股息率 ≥ | 数值门槛 |
| 排除亏损 | PE≤0 或缺失则去掉 |
| 仅有分红 | 股息率>0 |

排序：点表头切换升降序。文本列默认升序；数值列首次默认降序。`None` 在升序沉底、降序仍沉底（用 `±inf` 哨兵）。

底栏汇总：当前显示条数 / 总家数、盈利股 PE(TTM) 中位数、股息率中位数、更新时间、是否缓存。

**状态：已完成。**

### 步骤 10：导出当前结果

导出对象是 **当前筛选表 `view_rows`**，不是未过滤全市场（筛选为「全部」时即全市场）。

- CSV：`utf-8-sig`，Excel 直接打开不乱码
- xlsx：`openpyxl`；缺库时提示安装
- 默认文件名 `ashare_pe_yield_YYYYMMDD_HHMMSS.csv|.xlsx`
- 表头与界面列一致

**状态：已完成。**

## 4. 已实现内容清单（本提交包含）

本提交将下列实现一并入库。

### 4.1 文件

| 文件 | 作用 |
|------|------|
| `ashare_query/ashare_pe_yield.py` | 采集、缓存、筛选、Tk 界面、导出，单文件可运行 |

运行时生成、不入库：`ashare_query/cache/last_quote.json`。

### 4.2 已实现功能

1. **自动查询**：打开程序约 200 ms 后后台拉取全部 A 股最新行情
2. **全市场列表**：代码、名称、板块、行业、最新价、涨跌幅、三种 PE、股息率、市净率、总市值
3. **手动刷新 / F5**；可选 30～300 秒自动刷新
4. **筛选**：关键字、板块、PE 区间、最低股息率、排除亏损、仅有分红
5. **排序**：点击列标题
6. **导出**：当前表格 → CSV 或 Excel
7. **跳转**：双击或右键打开东方财富个股页
8. **复制**：Ctrl+C / 右键复制选中行（含表头，制表符分隔）
9. **容错**：三域名、分页并发、本地缓存回退、缺依赖提示

### 4.3 实现方式摘要

- **数据**：不爬 HTML，直接请求东财 `push2` JSON；`fs` 覆盖沪深京；`f9/f114/f115/f133` 对应动态 PE、静态 PE、TTM PE、股息率
- **规模**：发现 `pz>100` 仍只返回 100 条后改为按 `total` 分页；4 线程拉页，按页号重组
- **界面**：tkinter 自绘顶栏按钮 + ttk.Treeview；网络在后台线程，避免 GUI 冻结
- **兼容**：按 Python 3.7 编写（无 `list[str]`、无 `match`），适配本机 32-bit Python 3.7.9
- **启动**：bat 固定工作目录，避免「从别的盘符双击找不到脚本」

### 4.4 关键代码路径

```text
main()
  → AShareApp.__init__
      → after(200, refresh_async)
          → Thread: fetch_ashare_quotes
                → _fetch_page × N（4 线程）
                → classify_row
                → save_cache
          → _on_fetch_ok → apply_filter → _reload_tree
```

用户改筛选条件时只走 `apply_filter()`，不再访问网络。

## 6. 使用方法

```bat

python ashare_pe_yield.py
```

或直接双击 `启动A股查询.bat`。

## 7. 风险与限制

- 数据来自东财公开接口，可能有延迟，字段定义东财可能调整
- 全市场拉取受网络影响，大约数十秒；进度在状态栏显示
- 请勿把刷新间隔设得过短，以免请求被限流
- 本工具只做展示与导出，不构成投资建议
