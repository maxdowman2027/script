3. 主要发现

  • 整体趋势: WiFi格式之间的EVM差异主要集中在低速率(mcs0)和高发射功率情况下
  • 显著差异: 存在8个显著差异记录(>2dB)
  • 需要关注: 重点检查平均绝对差值大于2dB的配置，这些差异可能表明产品性能问题

4. 使用建议

  1. 检查8个显著差异记录(>2dB)，重点关注mcs0在高TX Power的情况
  2. 分析特定格式组合(如hesu vs ht, ht vs vht, vht vs hesu)的性能差异
  3. 对差异较大的测试条件进行硬件验证，以确认是否为实际硬件问题
  4. 检查测试配置是否一致，包括cable_loss、tx_shr、bb_scale等参数是否匹配
